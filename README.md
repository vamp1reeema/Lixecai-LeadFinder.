# Lixecai LeadFinder

Сканер указанных публичных Telegram-каналов и публичных страниц групп. Он не входит в личный Telegram-аккаунт и не читает личные переписки.

## Как работает
- Проверяет список публичных источников из `settings.json`.
- Загружает доступные публичные страницы вида `https://t.me/s/username`.
- Ищет ключевые фразы и отправляет совпадения в твой Telegram-бот.
- Не пишет авторам сообщений и не рассылает рекламу.

## Важные ограничения
- Сканер не может искать по всему Telegram и не умеет сам находить все публичные чаты.
- В `public_sources` нужно вручную добавлять username публичных каналов/страниц, которые доступны без входа.
- Публичная веб-страница Telegram показывает только часть сообщений. Некоторые публичные группы не отдают историю через такой просмотр; такие источники могут не поддерживаться.
- Это не авторизованный Telegram-клиент. Личные чаты и закрытые группы недоступны.

## Настройка источников
Открой `settings.json` и замени примеры в `public_sources` на username нужных публичных источников без @ и без ссылки. Например:
```json
"public_sources": ["some_public_channel", "another_public_group"]
```

## GitHub Secrets
Открой **Settings → Secrets and variables → Actions** и добавь только:
- `BOT_TOKEN` — токен уведомляющего бота от @BotFather.
- `BOT_CHAT_ID` — ID чата, куда бот отправляет уведомления.

Для этого варианта НЕ нужны `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_SESSION`.

Чтобы бот мог написать тебе, сначала открой его в Telegram и нажми Start.

## Запуск
Открой **Actions → LeadFinder → Run workflow**. По расписанию GitHub Actions запускает сканер примерно раз в 5 минут; запуск может задерживаться. Это не круглосуточный сервер.

## Настройка поиска
Меняй `keywords`, `ignore_words`, `scan_limit_per_source` и `public_sources` в `settings.json`.

Сканер использует публичные веб-страницы Telegram. Если Telegram изменит их разметку или ограничит доступ, сбор может перестать работать. SQLite сохраняется через GitHub Actions cache, который не является гарантированным постоянным хранилищем.
